# Modsmith: спецификация (2026-10-22, одобрено в чате)

Сайт, который по описанию на русском или английском собирает совместимый модпак Minecraft.

## Требования пользователя
- Сайт (GitHub Pages), без платного ИИ, выдача `.mrpack` + zip с .jar.
- Стиль: тёмный современный Minecraft, немного glass, много плавных анимаций.
- Автор во всех коммитах только askjjkk.

## Поведение
1. Ввод: описание; версия (список релизов с Modrinth); загрузчик Fabric / Forge / NeoForge / Quilt; размер: лёгкая 15, обычная 30, большая 60; переключатели «оптимизация» и «удобства». Версию и загрузчик можно написать в тексте («1.20.1 forge»).
2. Темы распознаются по ходу набора (чипы появляются вживую).
3. «Собрать» → анимация верстака + XP-полоса → карточки модов по темам с причиной выбора; галочкой можно убрать мод.
4. Выдача: `.mrpack` (formatVersion 1, хеши sha1/sha512, env, downloads, fileSize, зависимости minecraft + загрузчик) и zip (`mods/*.jar` + `КАК-УСТАНОВИТЬ.txt`). Ссылка «Поделиться» (`#q=…&v=…&l=…&s=…`).

## Подбор
- Словарь ~40 тем: основы слов RU/EN → категории и поисковые запросы Modrinth.
- База: оптимизация и удобства по загрузчику; дальше темы делят оставшийся бюджет, внутри темы по скачиваниям. Нет тем → «ванилла+».
- Для каждого мода берётся версия под (minecraft, загрузчик); нет → мод выкидывается.
- Обязательные зависимости рекурсивно; не нашлась зависимость → мод выкидывается.
- Несовместимости из метаданных → остаётся более популярный. Эксклюзивные группы: рендер, шейдеры, мини-карта, карта мира, просмотр рецептов.
- Библиотеки не выбираются как «темы», только как зависимости.

## Устройство
Чистые HTML/CSS/JS (ES-модули), JSZip с cdnjs. Файлы: `js/themes.js`, `js/parser.js`, `js/modrinth.js`, `js/builder.js`, `js/mrpack.js`, `js/ui.js`, `js/bg.js`. Тесты: `tests.html` (в браузере). Проверка выдачи: `tools/check_pack.py` (скачивает файлы из .mrpack и сверяет хеши).

## Ошибки
Нет сети / лимит Modrinth → понятное сообщение и повтор; 0 модов под версию → совет выбрать другую версию; мод без версии → тихо пропускается и попадает в «не подошли».
